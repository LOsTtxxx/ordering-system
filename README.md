# CLI 點餐系統
這是用 Python 寫的簡易點餐系統，此系統支援商品新增、刪除、修改以及結帳功能。

## 版本說明
☛ V1 (基礎版)
- 商品輸入與數量累加
- 檢查商品是否存在，避免輸入錯誤
- 輸入「結束」進行結帳
- 計算每個商品金額與總金額
- 顯示購買明細

☛ V2 (進階版)  
在 V1 基礎上加入指令式操作：  

- 新增商品（商品名稱 + 數量）
- 更改商品數量（更改 商品名稱 數量）
- 刪除商品（刪除 商品名稱）
- 防止輸入不存在的商品
- 更靈活的操作方式（CLI 指令操作）

☛ V3 (重構版)  
在 V2 基礎上將邏輯拆分為函式：  
- add_item() 負責新增商品
- delete_item() 負責刪除商品
- update_item() 負責更改數量
- checkout() 負責結帳明細
- 程式碼結構更清晰，易於維護

☛ V4 (錯誤處理版)  
在 V3 基礎上改善錯誤處理：  
- 將 isdigit() 換成 try/except
- 更標準的錯誤處理方式
- 程式更穩健

## 使用方法
- 新增商品:  
格式：商品名稱 數量  
範例：蛋糕 2  

- 更改商品數量:  
格式：更改 商品名稱 數量  
範例：更改 紅茶 5  

- 刪除商品:  
格式：刪除 商品名稱  
範例：刪除 紅茶  

- 結束結帳  
結束  

## 輸出結果
- 結帳後會顯示：

蛋糕 x 2 = 160  
咖啡 x 1 = 50  
總金額 = 210
